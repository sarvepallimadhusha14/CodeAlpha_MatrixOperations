# CodeAlpha Matrix Operations

## Description

This project implements common matrix operations using C programming.

## Features

* Matrix Addition
* Matrix Multiplication
* Matrix Transpose
* Modular design using functions
* 2D Arrays implementation

## Technologies Used

* C Programming
* GCC Compiler
* Visual Studio Code

## How to Run

Compile:
gcc matrix_operations.c -o matrix_operations

Run:
matrix_operations

## Learning Outcomes

* Functions
* Two-Dimensional Arrays
* Matrix Manipulation
* Nested Loops
